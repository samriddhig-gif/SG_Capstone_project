# Demo guide

The recorded screen demonstration is included as `demo.mp4`. It is under two minutes.

Suggested sequence:
1. Introduce the ZentroMart AI support agent and its four stages.
2. Show a policy question, generated answer and retrieved evidence IDs.
3. Show the delayed-order flow requesting order ID and verification before disclosing order details.
4. Show a successful ticket-creation example only if the displayed tool event confirms `created: true`.
5. Show a saved Gnani transcript, text reply, evidence trace and generated WAV playback.

Use only synthetic course data. Do not display API keys, `.env`, verification values or real customer information. Do not present a refusal or an unnecessary escalation as a successful business outcome.
